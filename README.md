# Expense Calculator

A simple Python command-line expense calculator built as part of my AI Engineering learning journey.

## Features

* Add any number of expenses
* Supports positive and negative values
* Calculates total expenses
* Calculates average expense
* Finds the minimum expense
* Finds the maximum expense
* Uses Python functions, lists, loops, and user input

## How to Run

Make sure Python is installed, then run:

```bash
python expensescalc.py
```

## How to Use

Enter your expenses one at a time.

Type:

```text
calc
```

when you want to stop entering expenses and see the results.

## Example

```text
enter your expenses: 200
enter your expenses: 300
enter your expenses: 150
enter your expenses: calc

avg is: 216.66666666666666
total expenses is: 650
minimum expenses is: 150
max expenses is: 300
```
